# EpicBosses

EpicBosses is a low-performance Minecraft mod for Fabric 1.21.11 that adds unique and challenging bosses to the game. This mod is designed to enhance the gameplay experience by introducing powerful and memorable enemies that players can encounter in various biomes and dimensions.

## Install

1. Download the mod file from the releases section of the GitHub repository.
2. Place the downloaded file into the `mods` folder of your Minecraft instance.
3. Launch Minecraft with the Fabric loader installed.

## Use

1. Start a new world or load an existing one.
2. Explore different biomes and dimensions to encounter the new bosses.
3. Prepare for a challenging fight against these powerful enemies.
